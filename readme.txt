# InnovateX Club – College Club Website  
A multi-page college club website built using **HTML** and **Basic CSS**.  
This project demonstrates clean structure, semantic HTML, float & flexbox layouts, forms, and consistent theming.
---

## 🧠 Features

### ✔ Common Navigation Bar  
- Logo + Club Name  
- Links to all pages  
- Dark blue theme styling  
- Responsive using Flexbox  

### ✔ Home Page  
- Hero section  
- Intro content  
- Clean layout  

### ✔ About Page  
- Description of the club (4–5 lines)  
- Relevant club image  
- Clean typography  

### ✔ Events Page  
- Three event/activity cards  
- Each includes:
  - Event Title  
  - Short description  
  - Background color + border  
- Entire section aligned using **Flexbox**

### ✔ Join Page  
A complete HTML form containing:  
- Name  
- Branch  
- Year  
- Email  
- Submit Button  
Beautifully styled using CSS.

---

## 🎨 Technologies Used
- **HTML5**
- **Basic CSS**
- **Flexbox**
- **Float**
- **Forms**
- **GitHub Pages** (for publishing)
